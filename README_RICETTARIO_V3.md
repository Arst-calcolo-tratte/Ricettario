# Ricettario — V3

Questa versione parte dalla V2 e aggiunge:
- modifica completa delle ricette già salvate;
- sostituzione diretta della foto di copertina;
- gestione della galleria: imposta una foto come copertina / elimina foto;
- mantenimento di ingredienti, passaggi, tag, categoria e tempi durante la modifica;
- UI della scheda ricetta rifinita per rendere più evidente modifica e foto;
- modalità cucina, preferiti, ricerca e chat della V2 mantenute.

## Deploy
Sostituire i file del repository GitHub con il contenuto di questa cartella e creare un commit. Non eliminare Supabase, Cloudflare Pages o OneSignal.

## Nota
Il build completo non è stato eseguito in questo ambiente perché l'installazione npm non ha completato entro il timeout disponibile. Prima del deploy verificare con `npm install` e `npm run build`.
